## 📖 About

**Emerald City Roleplay (ECRP)** adalah komunitas **SA-MP Roleplay** yang berfokus pada pengalaman bermain yang realistis, immersive, dan menyenangkan.

Di Emerald City, setiap pemain memiliki kesempatan untuk membangun karakter, menciptakan cerita, membangun karier, bergabung dengan faction, menjalankan bisnis, hingga terlibat dalam berbagai kejadian di kota.

## 📜 Roleplay Rules

Seluruh pemain wajib mengikuti peraturan Emerald City Roleplay.

Beberapa aturan utama:

- 🚫 No Metagaming (MG)
- 🚫 No Powergaming (PG)
- 🚫 No Random Deathmatch (RDM)
- 🚫 No Vehicle Deathmatch (VDM)
- 🚫 No Combat Logging
- 🚫 No Fear RP
- 🚫 No Abuse / Exploit
- 🚫 No Mixing IC & OOC
- 🚫 No Non-RP Name
- 🚫 Dilarang menggunakan Cheat

Pelanggaran terhadap peraturan dapat dikenakan hukuman sesuai tingkat pelanggaran.
