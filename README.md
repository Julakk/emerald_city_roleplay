## 📖 About

**Emerald City Roleplay (ECRP)** adalah gamemode **San Andreas Multiplayer (SA-MP)** yang dikembangkan untuk menghadirkan pengalaman roleplay yang immersive, interaktif, dan terus berkembang.

Project ini memiliki berbagai sistem yang mendukung pengalaman bermain, mulai dari sistem karakter, ekonomi, kendaraan, bisnis, faction, hingga berbagai fitur roleplay lainnya.

## 🔐 Security

Security dan stabilitas menjadi salah satu fokus utama pengembangan ECRP.

Beberapa perbaikan yang telah dilakukan meliputi:

- SQL Injection prevention
- Format String vulnerability fixes
- Buffer Overflow fixes
- Permission validation
- Input validation
- Array bounds validation
- Duplication exploit fixes
- Player data validation
- Transaction & balance validation

Seluruh security fix dan perubahan sistem dapat dilihat pada:
